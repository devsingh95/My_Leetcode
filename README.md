##  Repo structure (convention)
Each problem follows this layout:

/{difficulty}/{LC-####_Problem-Title}/
- solution.py (or solution.cpp, Solution.java)
- README.md (short approach, complexity, tags)
- test/ (optional small input tests)

Example:
- easy/LC-0001_Two-Sum/
  - solution.py
  - README.md

Naming rules:
- LC-XXXX prefix = LeetCode problem ID (zero-padded)
- Use hyphens for readability after the ID

##  How I write a problem entry
1. Create folder with format: {difficulty}/LC-0000_Problem-Name
2. Add solution file(s) with clear function signature
3. Add a README.md with:
   - Problem link
   - Short approach summary
   - Time / Space complexity
   - Tags (e.g., two-pointers, dp, graph)
4. Add small test cases in `test/` if helpful

Example README snippet (inside a problem folder):
- Problem: https://leetcode.com/problems/two-sum/
- Approach: Hash map one-pass
- Complexity: O(n) time, O(n) space
- Tags: array, hash-table
